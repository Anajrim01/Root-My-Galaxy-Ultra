## What's new

### SusFS fixes

- Updated the bundled Samsung SusFS payload with selected current upstream fixes.
- Added legacy 32-bit `stat`, `lstat` and `fstat` handling with the correct buffer layout and field-width checks.
- Kept stat-buffer access non-faulting inside the Samsung syscall tracepoint.
- Corrected the loader's symbol matching so a kernel import cannot resolve to a symbol belonging to another loaded module.
- Updated the BZIG and BZID profile checksums and source metadata for the new shared SusFS payload.

### KernelSU-Next compatibility

- Kept SusFS loading and unloading under Root My Galaxy Ultra's control, preventing KernelSU-Next's new loader from replacing or unloading the matching Samsung payload. Manager status queries remain available.

## Updating

1. Install **RootMyGalaxyUltra-1.2.5.apk** over the existing app; it uses the same package and release signing key.
2. Perform a **full reboot** to replace the loaded backend and SusFS module. A soft reboot keeps the existing kernel modules loaded.
3. Activate root again through Root My Galaxy Ultra. SusFS loads automatically when enabled in the app.

Use a **UAPI 5-compatible manager** for your selected backend. Updating the manager alone does not replace the loaded driver.
