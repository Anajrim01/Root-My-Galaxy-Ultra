## What's new

### SusFS R18 fixes

- Updated the bundled Samsung SusFS LKM with selected upstream **SusFS 2.3.0 R18** fixes, tested on **SM-S948B / BZIG**.
- Improved directory-listing scrubbing, including discarded records and hidden-name residue in all-hidden chunks, for native and 32-bit compatibility callers. User-buffer writes remain non-faulting inside the Samsung syscall tracepoint.
- Improved file-redirect rule publication and preserved an existing working rule when the redirect table is full.
- Prevented late probe registration during module unload and made probe-registration retries safe.
- Added overflow-resistant ELF section and section-table checks to the Samsung SusFS loader.
- Updated the BZIG and BZID profile checksums and source metadata for the new shared SusFS payload. The mount-recognition and filesystem-statistics fixes from 1.2.2 are retained.

### Release packaging

- Corrected the standalone release workflow's APK names and update instructions for Root My Galaxy Ultra.
- The public release contains the normal production APK.

## Updating

1. Install **RootMyGalaxyUltra-1.2.3.apk** over the existing app; it uses the same package and release signing key.
2. Perform a **full reboot** to replace the loaded backend and SusFS module. A soft reboot keeps the existing kernel modules loaded.
3. Activate root again through Root My Galaxy Ultra and enable SusFS in the updated app.

Use a **UAPI 5-compatible manager** for your selected backend. Updating the manager alone does not replace the loaded driver. If you used **RMGU SusFS R18 test**, turn off automatic SusFS in that test copy and use the production app for subsequent loads.
