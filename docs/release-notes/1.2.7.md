## What's new

### Samsung soft reboot fix

- Updated Samsung soft reboot handling to restart active hardware composer services before Android's framework starts again, addressing reported stuck displays and Samsung DeX failures.
- Added composer service discovery from the device's init configuration using stock Android shell utilities.
- Added bounded stop/start polling and best-effort service recovery after failures or interruption.
- Integrated [PR #12](https://github.com/xorpix/Root-My-Galaxy-Ultra/pull/12), with thanks to [@Anajrim01](https://github.com/Anajrim01) for the original fix.

## Updating

1. Install **RootMyGalaxyUltra-1.2.7.apk** over the existing app; it uses the same package and release signing key.
2. Perform a **full reboot** to replace the loaded backend and SusFS module. A soft reboot keeps the existing kernel modules loaded.
3. Activate root again through Root My Galaxy Ultra. SusFS loads automatically when enabled in the app.

Use a **UAPI 5-compatible manager** for your selected backend. Updating the manager alone does not replace the loaded driver.
